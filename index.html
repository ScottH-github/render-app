模型與 ControlNet 搭配指南

核心規則

Checkpoint 與 ControlNet 必須使用相同架構（如 SDXL 配 SDXL），否則會產生 tensor shape 錯誤。

可用搭配

SDXL

Checkpoint

InteriorSceneXL（⭐室內設計首選）· JuggernautXL · RealVisXL · NoobAI-XL · NightVisionXL · ZavyChromaXL

LoRA 增強

Interior-Design-Universal（搭配 InteriorSceneXL 自動載入）· Hyper-SDXL-8steps（加速渲染）

ControlNet

noob-sdxl 系列（canny / depth / lineart / normal / scribble / softedge / tile / openpose）、xinsir union、sdxl qrcode

SD1.5

Checkpoint

DreamShaper 8 · Serenity

ControlNet

control_v11p_sd15 系列（canny / depth / lineart / softedge / scribble / openpose / tile / inpaint / normalbae / seg）、sd15 qrcode

FLUX

Checkpoint

FLUX.1-dev（高品質通用，20-30 步）· FLUX.1-schnell（極速，4 步）

支援格式

.gguf（使用 UnetLoaderGGUF + DualCLIPLoader + VAELoader）· .safetensors（使用 CheckpointLoaderSimple）

ControlNet

Union-Pro 2.0 · Inpainting Beta

FLUX 使用 cfg=1.0、euler sampler、simple scheduler；不使用負面提示詞

使用說明

快速入門

1
上傳圖片

點選上傳區塊或拖放平面圖、3D 渲染截圖、照片至上傳區。支援 JPG、PNG 等圖片格式。

2
選擇模型

點選「場景預設」按鈕自動配置最佳組合，或從下拉選單手動選取。室內設計首選：InteriorSceneXL（自動搭配 Interior-Design LoRA）。

3
輸入提示詞

描述你想要的渲染效果，中英文皆可。點「AI」按鈕可自動優化提示詞。

範例：modern minimalist living room, warm lighting, wooden floor, large windows, photorealistic

4
點擊「渲染」

等待 AI 處理完成即可取得渲染結果。

進階功能

ControlNet

控制 AI 保留原圖哪些特徵。SketchUp 線圖用 Canny（保留邊緣線條）；風格轉換用 Depth（鎖定空間配置）。場景預設會自動選擇最佳類型。

重繪幅度 (Denoise)

0.4~0.55：風格轉換（保留配置改材質）
0.7~0.8：SketchUp 線圖寫實渲染
0.8~0.9：大幅重繪（需搭配 ControlNet）

畫筆標註

上傳圖片後可使用畫筆、顏色、形狀工具在圖上標註重點區域。按 Ctrl+Z 可復原。

負面提示詞

AI 優化後會自動產生負面提示詞，排除不想要的元素（如模糊、浮水印等）。

模型選擇建議

提示詞技巧

✦

描述具體：用具體的材質、光線、風格描述，效果比模糊描述好很多。

✦

英文為主：模型主要以英文訓練，英文提示詞效果通常更好。AI 按鈕會自動翻譯。

✦

加入品質詞：如 masterpiece, best quality, 8k, photorealistic, professional photography。

✦

指定攝影風格：如 wide angle lens, soft natural lighting, golden hour, magazine photography。
