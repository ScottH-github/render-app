# RENDER-APP 需求規格文件 (PRD)

本文件根據歷史對話記錄整理，詳述 **RENDER-APP** 的功能需求、技術指標與設計目標。

---

## 1. 產品目標
建立一個高效、私密且具備專業美感的 AI 渲染輔助工具，讓設計師能透過簡單的標註與提示詞，快速將平面圖或 3D 模型草稿轉化為高品質的渲染效果圖。

---

## 2. 核心功能需求

### 2.1 影像標註系統 (Annotation Tools)
*   **多格式上傳**:
    *   支援上傳平面圖 (Floor Plans) 指令、SketchUp 3B 模型截圖或各類輔助圖片。
    *   支援格式：PNG, JPG, SVG, 以及預計擴展的 3D 原始檔 (.skp, .usdz, .obj)。
*   **交互標註工具**:
    *   **畫筆 (Brush)**: 自由塗鴉，用於指定特定區域的修改風格。
    *   **色塊挑選 (Color Picker)**: 支援自定義顏色，用於引導 AI 的顏色偏好。
    *   **形狀框選 (Shape Tool)**: 快速圈定特定物體或空間區域。
*   **持久化狀態**:
    *   頁面重整或暫時關閉後，應能恢復前次的圖片與標註進度。

### 2.2 AI 渲染集成 (AI Integration)
*   **本地算力轉向**:
    *   移除對外部雲端 API 的依賴，全面接軌本地 ComfyUI (192.168.0.242:8188)。
    *   實現「零成本」渲染。
*   **Prompt 與引導**:
    *   提供文字輸入框，讓用戶定義渲染優先級（如：材質、光影、風格）。
    *   結合標註圖層與原始圖片，透過 `VAEEncode` 或 `ControlNet` 方式引導 AI。
*   **疊代優化 (Refinement)**:
    *   支援對渲染結果進行「再標註」並重新渲染（img2img 疊代）。

---

## 3. 非功能性需求

### 3.1 效能與優化
*   **等待時間監控**: 需監控各 AI 模組的處理時長，並尋求優化方案以減少渲染延遲。
*   **即時反饋**: 在渲染過程中需提供明顯的狀態提示（Loading 狀態、排隊進度）。

### 3.2 UI/UX 設計規範 (Premium Aesthetics)
*   **現代美學**: 採用深色模式 (Dark Mode) 與玻璃擬態 (Glassmorphism) 風格。
*   **微互動**: 按鈕懸停效果、Canvas 切換動畫、渲染完成後的平滑過渡。
*   **避免 Placeholder**: 介面中不應出現空的佔位圖，應預設美觀的空狀態。

### 3.3 安全性與可靠性
*   **CORS 處理**: 透過代理伺服器 (Cloudflare Workers) 確保前端與本地 API 的通訊安全且不被跨域限制阻擋。
*   **自動化檢測**: 整合 Playwright 測試，確保上傳、繪圖、渲染按鈕邏輯在每次更新後皆能正常運作。

## 4. 歷史修改記錄 (相關對話摘要)
*   **ComfyUI 集成**: 確立本地 IP 連接與圖片上傳、Prompt 送出的開發模式。
*   **API 瘦身**: 移除原有的雲端 API 金鑰暴露風險，改由代理與本地部署處理。
*   **Wait Time 追蹤**: 針對 AI 渲染各環節的時間消耗進行優化討論。
*   **標註工具增強**: 確定了筆刷、顏色、形狀三位一體的引導標註需求。
